# 🌐 Devf_practica_deployed

En este proyecto practicamos como hacer un html sencillo un readme.md 
y llevarlo a deployed en git pages.
Visitar la pagina en el siguiente enlace:
👉 **GitHub Pages:**\
`https://agocode.github.io/devf_practica_deployed/`

------------------------------------------------------------------------

## 📦 Clonar el repositorio

Para descargar el proyecto en tu máquina local, ejecuta el siguiente
comando en tu terminal:

``` bash
git clone https://github.com/Agocode/devf_practica_deployed.git
```

Después, entra a la carpeta del proyecto:

``` bash
cd devf_practica_deployed
```

------------------------------------------------------------------------

## 🧑‍💻 Abrir el proyecto en Visual Studio Code

Si tienes VS Code instalado, puedes abrir el proyecto con:

``` bash
code .
```

> Si el comando `code` no funciona, abre VS Code manualmente y
> selecciona **File → Open Folder**, luego elige la carpeta del
> proyecto.

------------------------------------------------------------------------

## 🚀 Ejecutar el proyecto con Live Server

Para visualizar la página en el navegador de forma local:

### 1️⃣ Instalar la extensión Live Server

En Visual Studio Code:

-   Ve a la sección **Extensions** (`Ctrl + Shift + X`)
-   Busca **Live Server**
-   Instala la extensión desarrollada por **Ritwick Dey**

------------------------------------------------------------------------

### 2️⃣ Iniciar el servidor

1.  Abre el archivo `index.html`
2.  Haz clic derecho
3.  Selecciona **"Open with Live Server"**

Tu navegador se abrirá automáticamente mostrando el proyecto.
